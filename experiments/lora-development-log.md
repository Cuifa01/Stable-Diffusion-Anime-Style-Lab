## 2026-11-09｜为什么调整对比实验

**观察：** 训练出的 LoRA 能体现可爱脸型、大眼睛和眼部反光，但部分发丝、衣服和阴影细节不足；`0.7–1.0` 各组视觉差异较小。

**权重调整：** 原实验缺少零权重组，不容易区分底模本身与 LoRA 的贡献。因此改成 **Baseline / 0 / 0.3 / 0.6 / 0.8 / 1.0**。

**角色调整：** 五个参考场景覆盖有限，新增 **Yuuka、Gawr Gura、Hoshino**，检查不同角色与服饰下画风是否一致。暂不能据此认定模型具有广义泛化能力。

**训练判断：** 细节不足尚不能直接归因于 Rank、训练步数或数据集；当前记录为主观观察，而非量化结论。

## 测试中解决的技术问题

- **LoRA 搜索路径：** 五个训练权重原先不在 NeoForge 扫描目录，随后移入中央模型库，完成哈希校验并刷新索引。
- **参数来源：** `test.txt` 曾与 PNG 元数据存在 Seed 差异，Youmu 的文本也曾有语法问题；已修正测试输入并保留历史差异记录。
- **API 校验：** 移除加权画师串后，返回元数据可能省略 `Emphasis`；初版校验器误报后已调整。
